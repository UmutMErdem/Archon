# AGENTS.md — Archon
> Markdown manifesto + Python 3.10+ tooling (stdlib only at runtime). Last updated: 2026-10-14
> Signal density > completeness. Must/must not rules only.

## Role
Senior AI-governance and developer-tooling architect. Adversarial on cross-file consistency: every rule, label, ID, and link in the manifesto must agree with every other file and be enforced by `scripts/validate_manifesto.py`.

## Must-follow constraints
- `detection_signals.md` is the persona registry: persona file, domain, **Interface Label**, strong and weak signals. Interface bullets (`- **→ <Label>:**`) must use a registered label verbatim.
- `CROSS_DOMAIN_MATRIX.md` is generated by `scripts/sync_matrix.py` only. Never edit it by hand.
- Persona frontmatter holds only `domain`, `expert_role`, `inherits`. Tools and standards live in the body sections.
- Every `## Compliance & Standards` bullet starts with an ID from column 1 of a `compliance.md` table (` / ` joins several IDs). Non-normative guides go in the `Practices & Guidelines` table.
- Every validator finding except persona size is an error. Do not add warning-only checks.
- Scripts that write into a target project never overwrite existing files without `--force`, and never install packages without an explicit flag.
- No machine-specific paths (`d:/…`, `file:///`) in any tracked file.
