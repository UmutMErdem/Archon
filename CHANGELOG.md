# Changelog

All notable changes to Archon are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- `scripts/archon_core.py` shared module, `scripts/detect_domain.py` tier proposer.
- Interface Label and Weak Signals columns in `detection_signals.md`.
- `Practices & Guidelines (non-normative)` table and missing standards in `compliance.md`.
- Validator checks: inheritance, placeholders, registry/README/Phase 0 registration, canonical labels, glob overlaps, matrix freshness, link anchors.
- `--check` for `sync_matrix.py`; argparse CLIs with `--force` for `bootstrap_target.py` and `create_persona.py`.
- `pyproject.toml`, pinned `requirements-dev.txt` / `requirements-graphify.txt`, Python 3.10 + 3.14 CI matrix.
- `planning/` documents for Archon itself.

### Changed
- `CROSS_DOMAIN_MATRIX.md` is generated by `sync_matrix.py` only, with one undirected diagram.
- Every validator finding except persona size fails the run.
- Finding IDs for target projects are `KI-NNN` / `F-NN`.
- Phase 0 Step 3, tier rules, graph linking, deferred-module rule, and reply-language rule clarified.
- Standards refreshed: INP, WCAG 2.2, RFC 9110, EU Machinery Regulation 2023/1230, WHATWG Fetch.

### Removed
- `generate_diagram.py`, `resolve_asymmetry.py`, `domain_utils.py`, `scripts/migrations/`, `requirements.txt`.
- `recommended_tools` / `compliance` lists from persona frontmatter.

### Fixed
- KI-001…KI-038 from the 2026-10-13 review, see [planning/KNOWN_ISSUES.md](planning/KNOWN_ISSUES.md).

### Security
- `graphify_helper.py` installs only with `--install`, pinned to `graphifyy==0.9.90`.
- `create_persona.py` rejects path-traversal filenames.
- CI token limited to `contents: read`.
